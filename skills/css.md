# Uso de Css

Al utilizar Css, intenta usar colores llamativos y haz que las letras sean legibles. 
Intenta que los tamaños de las letras sean adecuados y que las imagenes tengan un tamaño adecuado.
Utiliza colores que esten relacionados con el tema de tu pagina web.
Procura que tu pagina web se vea bonita y que sea facil de navegar.
