# Skill: Estructura obligatoria de salida

Cuando generes código, responde únicamente con esta estructura:

<project name="proyecto">

<file name="index.html">
contenido completo del archivo
</file>

<file name="style.css">
contenido completo del archivo
</file>

</project>

Reglas:
- No uses JSON.
- No uses Markdown.
- Cada archivo debe ir dentro de una etiqueta <file>.
- El nombre del proyecto debe ir en <project name="...">.
