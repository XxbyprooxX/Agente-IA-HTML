# Skill: Documentar código HTML

## Objetivo

Generar documentación clara y estructurada para código HTML.

## Instrucciones

* Explicar el propósito general de la página o componente.
* Describir la estructura principal del documento.
* Documentar etiquetas, secciones y elementos relevantes.
* Explicar atributos importantes (`id`, `class`, `src`, `href`, etc.).
* Agregar comentarios HTML cuando sea necesario para mejorar la comprensión.
* Incluir ejemplos de uso o integración si aplica.
* Crear una guía básica de estructura o README si se solicita.

## Formato de respuesta

Entregar:

1. Descripción general.
2. Explicación de la estructura HTML.
3. Descripción de elementos y atributos importantes.
4. Código HTML documentado.
5. README o guía de uso si aplica.
