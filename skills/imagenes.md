# Utilizar Imagenes

Si vas a utilizar imagenes en la pagina de HTML, puedes conectar a los siguientes sitios web para obtener imagenes:

- https://www.pexels.com/ 
- https://www.unsplash.com/ 
- https://pixabay.com/ 

Obviamente busca imagenes relacionadas con el tema de tu pagina web.
Intenta que las imagenes sean de alta calidad y que tengan una resolución adecuada para la web.
Evita utilizar imagenes de baja calidad o que no esten relacionadas con el tema de tu pagina web.
Pon las imagenes en un tamaño adecuado y que sean faciles de ver.
