# Skill: Crear código HTML

## Objetivo

Generar código HTML limpio, funcional, semántico, modular y comentado.

## Instrucciones

* Utilizar etiquetas HTML semánticas (`header`, `main`, `section`, `article`, `footer`, etc.) cuando corresponda.
* Mantener una estructura clara y ordenada.
* Incluir comentarios explicativos en las secciones importantes.
* Evitar prácticas inseguras o código obsoleto.
* Si se requiere interactividad, utilizar JavaScript separado en funciones bien definidas.
* Si se requiere diseño visual, incluir CSS organizado y fácil de modificar (El archivo css debe estar en el mismo directorio que el archivo html).
* Garantizar compatibilidad con navegadores modernos.
* Validar entradas del usuario cuando existan formularios.

## Formato de respuesta

Entregar siempre:

1. Nombre sugerido del archivo.
2. Explicación breve.
3. Código HTML completo.
4. Archivos adicionales necesarios (CSS, JavaScript, imágenes, etc.).
5. Instrucciones de uso o visualización.
6. Si vas a utilizar CSS, haz un link directamente al archivo dentro del html. No dejes nada fuera de los archivos.
