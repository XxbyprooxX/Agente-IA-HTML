# Skill: Revisar código HTML

## Objetivo

Analizar código HTML y detectar errores, riesgos o mejoras.

## Criterios de revisión

* Estructura y semántica del HTML.
* Accesibilidad (atributos `alt`, etiquetas, roles, etc.).
* Buenas prácticas de SEO.
* Claridad y organización del código.
* Uso correcto de etiquetas HTML.
* Posibles errores de renderizado o compatibilidad.
* Dependencias o recursos faltantes (CSS, JavaScript, fuentes, imágenes).

## Formato de respuesta

Responder con:

1. Diagnóstico general.
2. Errores encontrados.
3. Mejoras recomendadas.
4. Versión corregida si aplica.
